# City Boy, monographie d'un style

City Boy, monographie d'un style : l'histoire du city boy depuis le magazine Popeye, ses influences, 59 pièces expliquées, les couleurs, les silhouettes et un lookbook de 1 578 looks pour se l'approprier.

Site : https://florianzilliox.github.io/city-boy/

Fichiers générés par `python3 _build/build.py` (variable `CITYBOY_WEB=1`) ; ne pas modifier à la main.
Les photographies appartiennent à leurs auteurs. Pour toute demande de crédit ou de retrait, ouvrez une issue sur ce dépôt.
